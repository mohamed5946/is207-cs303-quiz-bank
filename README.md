# IS 207 + CS 303 Quiz Bank

بنك أسئلة مادتي الميدتيرم (الخميس 19 نوفمبر) — كل مادة ليها بنكها ونتيجتها لوحدها، والأسئلة مش مخلوطة ببعض.

- **IS 207 — Web Technology (79 سؤال)**: من أسئلة الكتاب (Practice Sheets) — HTML و CSS وأول أجزاء JavaScript.
- **CS 303 — Advanced Operating Systems (20 سؤال)**: تدريب الميدتيرم — 12 اختيارات + 8 صح/غلط، من غير مقالي.
- الإجابة النموذجية + شرح بالعربي بيظهر تحت كل سؤال بعد ما تختار إجابة.
- فلاتر حسب الموضوع، بحث، خلط، تدريب على الغلطات بس، وزرار «عشرين سؤال» بيجيب 20 سؤال عشوائي من بنك المادة دي بس.

## ملحوظات
- سؤال 13 في IS 207 مفهومه الـ hypertext، والاختيارات مافيهاش الكلمة دي — الأقرب منها (c) HTML.
- الأسئلة 1–5 في IS 207 متكررة في 75–79 زي ما هي في الكتاب.

الأسئلة في `quiz-data.json`، والموقع في `index.html` (نفس تصميم بنك أسئلة CS 309 و H 201).
