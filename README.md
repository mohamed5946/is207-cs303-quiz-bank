# IS 207 + CS 303 Quiz Bank

بنك أسئلة مادتي الميدتيرم (الخميس 19 نوفمبر) — كل مادة ليها بنكها ونتيجتها لوحدها، والأسئلة مش مخلوطة ببعض. بعد ما تختار المادة، اختار «مراجعة» (شرح المنهج كله جزء جزء من السلايدز والكتاب) أو «امتحان» (الأسئلة).

- **IS 207 — Web Technology (79 سؤال)**: من أسئلة الكتاب (Practice Sheets) — HTML و CSS وأول أجزاء JavaScript. المراجعة: 5 أجزاء — الويب والبروتوكولات، بنية HTML، الجداول والنماذج، CSS، وأول JavaScript.
- **CS 303 — Advanced Operating Systems (80 سؤال)**: تدريب الميدتيرم (20 سؤال — 12 اختيارات + 8 صح/غلط) + بنك الـ 100 سؤال (40 اختيارات + 20 صح/غلط) — من غير مقالي. المراجعة: 4 أجزاء — العمليات، الخيوط وقانون أمدال، التزامن، الجدولة.
- الإجابة النموذجية + شرح بالعربي بيظهر تحت كل سؤال بعد ما تختار إجابة.
- فلاتر حسب الموضوع، بحث، خلط، تدريب على الغلطات بس، وزرار «عشرين سؤال» بيجيب 20 سؤال عشوائي من بنك المادة دي بس.
- 4 أسئلة في CS 303 مواضيعها زيادة عن السلايدز والدليل — عليها علامة «خارج السلايدز» (C29: Copy-on-Write، C49: push/pull migration، C75: First Readers-Writers problem، C76: hard processor affinity) — للفهم بس، مش من السلايدز.

الأسئلة في `quiz-data.json`، والمراجعة في `revision-data.json`، والموقع في `index.html` (نفس تصميم بنك أسئلة CS 309 و H 201).
